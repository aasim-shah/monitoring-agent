## Summary

Signed-in users land on `/orgs`, see their organizations, and can create one. Inside an organization, a header, an organization/product switcher, and role-aware navigation frame every page. The product navigation follows spec §21 in order; sections not built yet are visible but disabled, labelled with the milestone that delivers them.
