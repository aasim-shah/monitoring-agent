## Summary

Five services exist with liveness and readiness endpoints, plus two shared health packages (TypeScript and Go). No business logic yet; each later milestone adds its module to these services.

## Delivered

| Path | Service / package | Endpoints |
|---|---|---|
| `packages/health` | `@pcp/health`: `ReadinessCheck`, `runChecks(checks, timeoutMs=2000)`, `postgresCheck(url)`, `redisCheck(url)` | — |
| `apps/api` | NestJS 11 on Fastify; `AppModule.register(config)`; `loadConfig(env)` (Zod) | `GET /healthz` → `{status, service:'api', deploymentMode}`; `GET /readyz` → 200 `ready` / 503 `not_ready` with per-check results |
| `apps/worker` | Node HTTP health server; `loadConfig(env)` | `GET /healthz`, `GET /readyz` (Redis) on `WORKER_HEALTH_PORT` (3002) |
| `apps/web` | Next.js 15.5 App Router, `output: 'standalone'` | `GET /healthz` → `{status:'ok', service:'web'}`; `/` placeholder page; port 3001 |
| `packages/go-platform` | Go module `pcp.local/platform`, package `health`: `Handler(service)`, `Probe(url)` | — |
| `apps/opamp-server` | Go; `healthcheck` subcommand | `GET /healthz` on `OPAMP_PORT` (4320) |
| `apps/ingest-gateway` | Go; `healthcheck` subcommand | `GET /healthz` on `INGEST_PORT` (4318) |
| `go.work` | Workspace: both Go services, `go-platform`, `agent-protocol/go` | — |

Configuration (env): `DEPLOYMENT_MODE` (`managed` default, `self_hosted`), `API_PORT` (3000), `DATABASE_URL`, `REDIS_URL`, `WORKER_HEALTH_PORT` (3002), `OPAMP_PORT`, `INGEST_PORT`. Invalid values fail at startup with the variable name.

Root scripts added: `pnpm test:go`, `pnpm vet:go`.

## Decisions

- Added `packages/health` and `packages/go-platform` (not in master §5) to share readiness logic instead of duplicating it per service.
- `/readyz` failure uses Nest's `ServiceUnavailableException` with the report as body, so no Fastify types leak into controllers.
- BullMQ wiring in the worker is deferred to M4.4, when the first queue exists.

## Known limitations

- `/healthz` and `/readyz` are not authenticated; Caddy must not route them publicly except `/healthz` for smoke checks (M1.3).
