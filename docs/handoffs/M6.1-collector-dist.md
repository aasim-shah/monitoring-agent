## Summary

The agent now ships with its own OpenTelemetry Collector build, `pcp-otelcol`, and `pcp-agentctl run` starts and supervises it. Host metrics go every 30 s over Prometheus remote_write with the agent's mTLS certificate. The distribution build produces checksummed tarballs for amd64 and arm64.

## Delivered

| Piece | Behavior |
|---|---|
| `agents/host-agent-go/collector/builder-config.yaml` | `ocb` v0.162.0: `host_metrics`; `batch`, `memory_limiter`, `resource_detection`; `prometheus_remote_write`; `file_storage`, `health_check` |
| `agents/release/Dockerfile` (`--target dist`) | Collector built with Go 1.26.9 (upstream requirement), `pcp-agentctl` with Go 1.23; `pcp-agent-<version>-linux-{amd64,arm64}.tar.gz` (~30 MB each), `SHA256SUMS`, `VERSION` |
| `internal/collector/config.go` | Configuration as JSON (valid YAML): scrapers cpu, memory, filesystem, network, load, disk every 30 s, utilization metrics enabled; `memory_limiter` (100 MiB) first; mTLS to `<ingest>/prometheus/api/v1/write` with certificate reload every 5 min (rotation); on-disk WAL; health check on 127.0.0.1 only; collector self-metrics off (no `:8888` listener) |
| `internal/collector/supervise.go` | Restarts the collector with backoff 1 s → 60 s (reset after 5 min healthy); SIGTERM then SIGKILL on stop |
| `pcp-agentctl` | `run` writes `collector.yaml` (0600) and supervises `/usr/local/bin/pcp-otelcol` (`--collector` to override; skipped with a log line when absent); `enroll --ingest-url` for development; `collector-config` prints the configuration; version set at build time |

## Metric names (verified against a real collector run)

| Use | Metric |
|---|---|
| CPU % | `1 - system_cpu_utilization_ratio{state="idle"}` (one series per state) |
| Memory % | `system_memory_utilization_ratio{state="used"}` |
| Disk % | `system_filesystem_utilization_ratio` (per `mountpoint`; absent inside containers) |
| Network | `system_network_io_bytes_total{direction="receive"\|"transmit", device}` |
| Load | `system_cpu_load_average_{1m,5m,15m}` |

Component names follow v0.162 (`host_metrics`, `resource_detection`, `prometheus_remote_write`); the old aliases log deprecation warnings.
