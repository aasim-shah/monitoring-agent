## Summary

`@pcp/connector-sdk` defines how every integration is written and what the platform guarantees around it: the contract, a registry that enforces capability declarations, the connection state machine, a bounded HTTP client, a circuit breaker, and secret redaction. `@pcp/connectors-mock` is a test-only connector used to exercise the whole lifecycle.

## Delivered

| Export | Behavior |
|---|---|
| `Connector`, `ExecutionContext` (+ `config`, `credentials()`), `ConnectionValidation`, `HealthResult`, `CatalogEntry` | Contract per spec §9; `configSchema()` returns JSON Schema so the UI and AI registry can render it |
| `ConnectorRegistry` | `register` rejects a declared capability without its method, a method without its declared capability, and duplicates; `list()` returns the catalog |
| `transition(from, event)` | Lifecycle per spec §9.1; `disconnected`/`revoked` terminal; illegal moves throw |
| `createHttpClient(opts)` | 10 s timeout, 5 MB limit (streamed), 3 retries with full jitter on 429/5xx/network, honors `Retry-After`; final failure → `ConnectorError('rate_limited' \| 'provider_unavailable')` |
| `CircuitBreaker` | Opens after 5 consecutive failures for 30 s; a failed half-open trial reopens |
| `ConnectorError(reason, message, { retryAfterSeconds })` | Diagnosable reasons, never a generic error |
| `redactSecrets(text, secrets)` | Replaces every occurrence of each secret (≥ 4 chars) |
| `@pcp/connectors-mock` | `type: 'mock'`; behaviors `ok`, `unauthorized`, `forbidden`, `rate_limited`, `unavailable`, `leaky` (error contains the credential, to prove redaction) |

## Decisions

- JSON Schema instead of Zod for `configSchema()` (ledger ruling).
- `ExecutionContext.credentials()` is an accessor so credentials are decrypted only when an operation needs them.
