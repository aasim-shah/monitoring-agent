## Summary

Customers can now add servers from the dashboard. The product setup checklist links "Add your servers" to the new Agents page. "Add server" creates a one-time install command for a chosen environment and fleet size, then shows servers as they connect. Each agent has a detail page with identity, heartbeats, diagnostics, and revocation.
