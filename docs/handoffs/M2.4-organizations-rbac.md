## Summary

Organizations, products, and environments now exist behind a global `TenantGuard`. Every route must be declared `@Public`, `@SessionOnly`, or `@RequirePermission` + `@TenantScope`, and a route-enumeration test fails if one is not. Any denial (unknown resource, non-member, missing permission, out-of-scope product, malformed ID) returns 404.

## Delivered

| Path | Purpose |
|---|---|
| `src/common/decorators.ts` | `@Public`, `@SessionOnly`, `@AllowMfaPending` (implies `@SessionOnly`), `@RequirePermission(p)`, `@TenantScope({ param })` |
| `src/common/tenant.guard.ts` | Global guard (after `OriginGuard`, `CurrentUserGuard`): resolves the organization from `orgId`, `productId` (`pcp_resolve_product_org`), or `environmentId`; loads the membership; builds `TenantContext` on `req.tenant`; checks `can()` including product scope |
| `src/common/tenant.ts` | `requireTenant(req)`, `isUniqueViolation(err)` |
| `src/modules/tenants/*` | `POST /api/v1/organizations` (creator becomes owner), `GET /api/v1/organizations/:orgId`, `PATCH /api/v1/organizations/:orgId/settings` |
| `src/modules/products/*` | `POST /api/v1/organizations/:orgId/products`, `GET /api/v1/products/:productId`, `POST /api/v1/products/:productId/environments`, `GET /api/v1/products/:productId/overview` |
| `packages/database/prisma/migrations/0002_environment_scope` | `pcp_resolve_environment_product(environment, user)` for product scope on environment routes |
| `test/security/tenant-matrix.int.test.ts` | Static and dynamic cross-tenant checks over every registered route |

Validation: organization name 1–100 characters; timezone must be a valid IANA zone; product domains must be hostnames; repositories `owner/name`; environment names unique per product (409 `environment_exists`); product names unique per organization (409 `product_exists`); settings accept `dataRetentionDays` 1–3650.

## Decisions

- `DiscoveryModule` is imported in `AppModule` so the tenant-matrix test can enumerate routes from the real application.
- Denials are always 404, including missing permissions inside one's own organization; the API never reveals whether a resource exists.
