## Summary

`docs/architecture/openapi-v1.yaml` is an OpenAPI 3.1 draft with 117 operations: every spec §15 route plus the routes the workbooks define. Every operation has an `operationId`, a tag, explicit `security`, and standard responses. Request and response bodies are added by the milestone that implements each route.

## Delivered

| File | Purpose |
|---|---|
| `docs/architecture/openapi-v1.yaml` | Draft contract; path-level `servers` for `agent.` and `ingest.` hosts |
| `.spectral.yaml` | `spectral:oas` recommended + error rule `operation-security-declared` |
| `scripts/__tests__/openapi.test.mjs` | Spec §15 coverage, security/operationId checks, security schemes |
| `package.json` | `lint:openapi` script; devDependencies `@stoplight/spectral-cli@6.15.1`, `yaml@2.8.4` |

Security schemes: `sessionCookie` (cookie `pcp_session`), `agentMtls` (mutualTLS), `webhookSignature` (header), `internalToken` (header `X-Internal-Token`). Public endpoints (sign-up, login, reset, Google login, agent enroll) declare `security: []`.

## Decisions

- Routes defined only in workbooks (identity, members, install sessions, alert rules, action policies, report schedules, organization export/deletion, internal endpoints) are now part of the contract.
- Out-of-scope access is documented as 404 (`NotFound` response), never 403.

## Known limitations

- No request/response schemas yet; each implementing milestone adds them and the typed client (M3.3) is generated from this file.
