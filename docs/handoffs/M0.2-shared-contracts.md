## Summary

Two packages now fix the vocabulary every later milestone uses. `@pcp/shared-contracts` holds the master-plan §4 types, constants, and Zod schemas. `@pcp/agent-protocol` holds the control-channel JSON Schemas, an Ajv validator, and generated TypeScript and Go types.

## How to verify

```bash
pnpm turbo run build lint typecheck test --filter @pcp/shared-contracts --filter @pcp/agent-protocol
pnpm --filter @pcp/agent-protocol generate      # regenerate after schema edits
scripts/go.sh -C packages/agent-protocol/go vet ./...
scripts/go.sh gofmt -l packages/agent-protocol/go # prints nothing when formatted
```

Key assertions: unknown capability rejected; confidence 1.5 and −0.1 rejected; observation with `organizationId` rejected; `EnrollRequest` with `organizationId` rejected; heartbeat without `sequence` rejected; task type `shell` rejected; generated files match schemas.

## Decisions

- Go module path `pcp.local/agentprotocol` (local workspace module, no public import path yet).
- Generator emits gofmt-aligned structs, so CI can run `gofmt -l` on generated code.
- ESLint ignores unused variables prefixed `_` (used for rest-sibling omission in tests).

## Known limitations

- Optional schema fields map to Go zero values with `omitempty`; pointer types are not used yet.
