## Summary

The building blocks authentication needs: envelope encryption (`@pcp/secrets`), argon2id password hashing, RFC 6238 TOTP, random tokens stored as hashes, server-side sessions with idle and absolute expiry, and a Redis rate limiter.

## Delivered

| Path | Exports |
|---|---|
| `packages/secrets/src/envelope.ts` | `encryptSecret`, `decryptSecret` (AES-256-GCM, per-secret data key wrapped by key-encryption key, AAD-bound), `serializeSecret`, `deserializeSecret` |
| `packages/secrets/src/key-ring.ts` | `loadKeyRing(env)`: `MASTER_KEY` (32 bytes base64), `MASTER_KEY_VERSION` (default 1), older `MASTER_KEY_V<n>` |
| `apps/api/src/modules/identity/password.ts` | `hashPassword`, `verifyPassword` (argon2id m=19456, t=2, p=1; malformed hash → false) |
| `apps/api/src/modules/identity/totp.ts` | `generateTotpSecret` (20 bytes base32), `totp`, `verifyTotp` (±1 step, constant-time), `otpauthUri`, base32 helpers |
| `apps/api/src/modules/identity/tokens.ts` | `randomToken` (256-bit base64url), `hashToken` (SHA-256 hex) |
| `apps/api/src/modules/identity/session.service.ts` | `SessionService.create / resolve / markMfaVerified / revoke / revokeAllForUser`; idle 12 h, absolute 7 days |
| `apps/api/src/modules/identity/rate-limiter.ts` | `RateLimiter.hit(key, limit=10, windowSeconds=60)` (Redis fixed window) |

## Decisions

- `packages/secrets` was pulled forward from M4.1 because TOTP secrets must be encrypted at rest.
- The wrapped data key binds to `wrap:<aad>`, so the wrapped key and the ciphertext are both tied to their owner.
