## Summary

The repository is now a pnpm 9 + Turborepo 2 monorepo with strict TypeScript defaults, ESLint 9 flat config, Prettier, and a repository-level test runner. No packages exist yet; later tasks add them under the workspace globs.

## Decisions

- pnpm is invoked through corepack (`corepack pnpm`), so no global install is required.
- Versions pinned to known-stable majors (TypeScript 5.9.3, Vitest 3.2.7, ESLint 9.39.5) rather than the newest majors available (TypeScript 7, Vitest 5). Upgrading is a separate, deliberate task.
- All TypeScript packages are ESM (`"type": "module"`).

## Known limitations

- `node --test` needs a glob (`'scripts/__tests__/*.test.mjs'`); passing the directory alone fails on Node 24.
