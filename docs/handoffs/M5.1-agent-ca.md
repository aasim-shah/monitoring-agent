## Summary

The API can now act as the agent intermediate CA. It signs host-generated P-256 CSRs into 30-day client certificates, and a script creates a development or self-hosted PKI in one command.

## Delivered

| File | Behavior |
|---|---|
| `apps/api/src/modules/agents/ca/ca.service.ts` | `AgentCa.fromPem(cert, key, chain)`; `issue(csrPem, agentId, now?)` → `CN=<agentId>`, EKU `clientAuth`, key usage `digitalSignature`, valid `now − 5 min … now + 30 days`, random positive serial, SHA-256 DER fingerprint (lowercase hex, matching Caddy) |
| `ca/csr.ts` | `parseCsr` accepts only ECDSA P-256 with a valid self-signature; anything else → `InvalidCsrError` |
| `ca/pki.ts` | `generateDevPki()`: root (10 y, pathlen 1) → intermediate (3 y, pathlen 0) → chain; Ed25519 task-signing key |
| `ca/x509.ts` | Loads `reflect-metadata` and points `@peculiar/x509` at Node's WebCrypto (the API compiles without the DOM lib) |
| `scripts/agent-pki.mjs` (`pnpm --filter @pcp/api agent:pki --out <dir>`) | Writes `root.pem`, `root.key` (0600, keep offline), `intermediate.pem`, `chain.pem`; prints `AGENT_CA_CERT`, `AGENT_CA_KEY`, `AGENT_CA_CHAIN`, `TASK_SIGNING_KEY` |
| `config.ts` | `AppConfig.agents` from `AGENT_CA_*`, `TASK_SIGNING_KEY`, `AGENT_CONTROL_URL`, `AGENT_INGEST_URL`, `AGENT_OPAMP_URL` (all or none; PEMs base64-encoded) and `AGENT_PROXY_ADDRESSES` |

Dependency: `@peculiar/x509` 2.1.0 (2.2.0 is under two weeks old).
