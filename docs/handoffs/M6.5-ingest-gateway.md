## Summary

Agent metrics now have a front door. The Go ingest gateway accepts Prometheus remote_write behind Caddy's mTLS edge, identifies the agent by certificate fingerprint, stamps the tenant labels itself, enforces the per-agent and per-tenant limits, and forwards to VictoriaMetrics.

## Delivered

| Piece | Behavior |
|---|---|
| `POST /prometheus/api/v1/write` | Fingerprint trusted only from `TRUSTED_PROXY_ADDRESSES` (socket peer); identity from the API's internal lookup, cached 30 s (unknown cached too); 401 otherwise |
| Label rewrite | Drops any client `tenant_id`, `product_id`, `environment_id`, `agent_id`; adds the agent's values; labels sorted |
| Limits | 20,000 series/agent/hour and 200,000/tenant/hour (new series beyond → 429 `Retry-After: 60`, known series pass); 10,000 samples/s per agent with 10 s burst (429 with `Retry-After`); 10 MB decompressed (413); samples > 1 h in the future dropped, all-future request → 400 |
| Forward | Snappy protobuf to `VM_WRITE_URL?extra_label=tenant_id=<org>`; storage errors → 503 so the collector retries |
| `POST /otlp/v1/{metrics,logs,traces}` | 501 until M6b/M10 |
| Codec (`remotewrite.go`) | Minimal prompb via `protowire` (exemplars, histograms, metadata dropped) |
| Compose | Gateway env `VM_WRITE_URL`, `API_INTERNAL_URL`, `INTERNAL_TOKEN`, `TRUSTED_PROXY_ADDRESSES`; waits for the API; `INTERNAL_TOKEN` now required for API and gateway (`.env.example`, smoke, e2e updated) |

Dependencies: `github.com/golang/snappy` v1.0.0, `google.golang.org/protobuf` v1.36.11 (Go 1.23-compatible).
