## Summary

A real one-line install now works. The platform serves `install.sh` and the release tarballs; the installer verifies checksums, creates the unprivileged `pcp-agent` user, enrolls the host, and starts a hardened systemd service. Verified end to end on an Ubuntu 24.04 systemd host: host metrics reached the dashboard API 81 s after the install started (before the latency change below).

## Delivered

| Piece | Behavior |
|---|---|
| `agents/host-agent-go/installer/install.sh` | `--token`, `--control-url`, `--download-url`, `--force`, `--uninstall` (+ development `--ca-file`, `--server-name`, `--ingest-url`); root and systemd required; amd64/arm64; downloads `VERSION`, `SHA256SUMS`, tarball and checks with `sha256sum` (mismatch → abort, nothing installed); `pcp-agent` system user; `/etc/pcp-agent` 0750, `/var/lib/pcp-agent` 0700; enrolls as `pcp-agent` via `runuser`; re-run upgrades and keeps the identity; `--uninstall` removes unit, binaries, user, and data |
| `packaging/systemd/pcp-agent.service` | `User=pcp-agent`, `NoNewPrivileges`, `ProtectSystem=strict`, `ProtectHome`, `PrivateTmp`, `ReadWritePaths=/var/lib/pcp-agent`, `Restart=always`; embedded into `install.sh` at build time |
| `agents/release/Dockerfile` target `downloads` + `agents/release/Caddyfile` | Caddy file server for `/install.sh` and `/downloads/*` (renamed from `agents/dist`, which `.dockerignore` excludes) |
| Compose `downloads` service; all Caddyfiles route `/install.sh` and `/downloads/*` | Edge Caddy waits for it |
| Install command | Adds `--download-url <APP_ORIGIN>/downloads` |
| VictoriaMetrics | `-search.latencyOffset=5s` so new data shows within seconds (default 30 s) |
