## Summary

The ingest gateway needs to map a client-certificate fingerprint to an agent's tenant scope. The API now answers that on a private-network route guarded by a shared token.

## Delivered

| Piece | Behavior |
|---|---|
| `GET /internal/agents/by-fingerprint/:fp` | `{ agentId, organizationId, productId, environmentId }` for a currently valid credential (active agent, unrevoked, unexpired, rotation grace 1 h), else 404 |
| `@Internal()` + `InternalGuard` (global) | Route off (404) without `INTERNAL_TOKEN`; otherwise `X-Internal-Token` must match (constant-time) or 401; implies `@Public()` |
| `INTERNAL_TOKEN` (config, Compose pass-through) | At least 24 characters; required by the gateway from Task 2 |
| Tenant matrix | New check: `/internal/` routes and only those carry `@Internal()` |
