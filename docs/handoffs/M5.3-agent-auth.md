## Summary

Agent routes now authenticate by client certificate. Caddy verifies the certificate and forwards its SHA-256 fingerprint. The API trusts that header only when the TCP peer is Caddy's fixed address, and checks the credential against the database through a 30-second cache.

## Delivered

| Piece | Behavior |
|---|---|
| `@AgentRoute()` (`common/decorators.ts`) | Marks agent control routes; implies `@Public()` so the user guards skip them. `@AgentEnroll()` marks the enroll bootstrap route. |
| `AgentAuthGuard` (global, runs after `OriginGuard`) | Peer address = `req.raw.socket.remoteAddress` (IPv4-mapped normalized), must be in `AGENT_PROXY_ADDRESSES`; `req.ip` / `X-Forwarded-For` are ignored. Fingerprint must be 64 hex chars. Accepts only an active agent with an unrevoked, unexpired credential (superseded credentials for 1 h). Sets `req.agent` and an agent `req.tenant`. Every failure → 401 `agent_unauthorized`. |
| `AgentIdentityCache` | `pcp_agent_by_fingerprint` results (including unknown) cached 30 s; `evict()` for immediate revocation (Task 7) |
| `GET /agent/v1/whoami` | Returns `{ agentId }`; used by `pcp-agentctl status` |
| `Caddyfile.production` | Agent site `client_auth verify_if_given` (enroll needs no certificate); ingest stays `require_and_verify`; both strip client-sent `X-Client-Cert-Fingerprint` |
| `Caddyfile.local` (new) | Laptop TLS: `tls internal` for `agent.localhost` / `ingest.localhost`, dashboard on plain `:80` |
| `compose.yaml` | `edge` subnet `${EDGE_SUBNET:-172.30.0.0/24}`, Caddy `${CADDY_ADDRESS:-172.30.0.10}`; API gets `AGENT_PROXY_ADDRESSES` and the agent PKI variables. Smoke and e2e stacks use their own subnets. |
| Tenant matrix | New check: routes under `/agent/` and only those carry agent authentication |
