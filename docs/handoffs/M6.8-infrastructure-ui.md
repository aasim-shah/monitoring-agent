## Summary

"Infrastructure" is live in the product menu. It lists every server with current CPU, memory, and disk, and each server has a metrics page with CPU, memory, network, and disk charts over 15 minutes to 7 days. Missing data shows as gaps and a plain-language banner, never as zeros.

## Delivered

| Piece | Behavior |
|---|---|
| `infrastructure/page.tsx` | One row per server: name, environment, status (+ Stale), "metrics N ago", CPU/Memory/Disk usage meters; refreshes every 30 s; empty state links to Add server |
| `infrastructure/[agentId]/page.tsx` | Range buttons 15m/1h/6h/24h/7d; CPU %, Memory %, Network in/out (B/s…GB/s), Disk % per mountpoint (3 fullest); stale banner; "Partial range" note beyond retention |
| `MetricChart` (Recharts 3.10.1) | 2px lines, `connectNulls={false}`, hairline horizontal grid, crosshair tooltip ("no data" for gaps), legend only for ≥ 2 series, data table under every chart (relief for the light-mode aqua slot) |
| `StaleBanner` | Nothing while fresh; "No data since … (N min ago)" after 2 min, noting that a missing agent alone does not mean the server is down; "No metrics yet" before the first sample |
| `UsageBar` | `role="meter"` with the value in text; ≥ 90 % adds a "High" label (not color alone); null → "no data" |
| Tokens | `--series-1..3` (dataviz reference palette slots blue/orange/aqua, light and dark) and `--chart-grid` in `globals.css` |
| Navigation / links | Infrastructure enabled for `telemetry.query`; agent detail links to its metrics and back |

Palette validation (`dataviz` validator, all-pairs): light on `#ffffff` passes with a contrast WARN for aqua (relief: data tables + legend); dark on `#111827` passes all checks.
