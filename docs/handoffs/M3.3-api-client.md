## Summary

`@pcp/api-client` turns `docs/architecture/openapi-v1.yaml` into TypeScript types and a typed `openapi-fetch` client. The dashboard calls the API through it, so request bodies, paths, and responses are checked at compile time against the contract.

## Delivered

| Path | Purpose |
|---|---|
| `scripts/generate.mjs` | openapi-typescript 7 → `src/schema.ts`; `--check` fails when the file is stale |
| `src/client.ts` | `createApiClient({ baseUrl?, fetch? })`: same-origin by default, `credentials: 'include'` |
| `src/errors.ts` | `ApiError { status, code, message, requestId }`; `unwrap(result)` returns data or throws `ApiError` |
| `src/index.ts` | Re-exports plus `Schemas = components['schemas']` |

## How to verify

```bash
pnpm turbo run build lint typecheck test --filter @pcp/api-client   # 5 tests
pnpm --filter @pcp/api-client generate                               # after editing openapi-v1.yaml
```

## Tests

| Test | Result |
|---|---|
| Generated types match `openapi-v1.yaml` | pass |

## Decisions

- The generated file is `schema.ts` (not `.d.ts`) so `tsc` emits it to `dist`.
- `src/schema.ts` is excluded from Prettier so the drift check compares the generator's exact output.
