## Summary

Agents can renew their certificate before it expires, and administrators can cut an agent off instantly. Revoking an enrollment token stops further hosts from joining with it.

## Delivered

| Route | Behavior |
|---|---|
| `POST /agent/v1/rotate` (`@AgentRoute()`) | `{ csrPem }` → 201 `{ certificatePem, chainPem, notAfter }`; the calling certificate gets `superseded_at` and keeps working for 1 h; audit `agent.certificate_rotated`; bad CSR → 400 `invalid_csr` |
| `POST /api/v1/agents/:id/revoke` (`agent.revoke`) | Agent `revoked`, all credentials revoked, queued/delivered tasks expired, open streams closed, audit `agent.revoked`; idempotent |
| `POST /api/v1/environments/:environmentId/agent-enrollments/:enrollmentId/revoke` (`agent.enroll`) | Token stops working (same 401 as unknown); enrolled agents unaffected; audited |
| `RevocationBus` | Publishes revoked fingerprints on Redis `agent-revoked`; every API process evicts them from `AgentIdentityCache` at once (the 30 s TTL remains the upper bound if Redis drops the message) |
