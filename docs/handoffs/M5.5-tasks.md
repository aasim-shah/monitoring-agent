## Summary

The control plane can send an agent a one-off task. Each task is Ed25519-signed, expires after 10 minutes by default, and is delivered by long-poll. The agent reports a result, and streaming results have a session-checked chunk endpoint.

## Delivered

| Piece | Behavior |
|---|---|
| `canonicalJson()` (`@pcp/agent-protocol`) | Signed bytes: keys sorted at every depth, no whitespace, **ASCII-only** (every UTF-16 unit ≥ U+007F as `\uXXXX`), safe integers only. Chosen so Go's encoder can match it byte for byte. |
| `testdata/task-signature.json` | Shared vector (test-only key) that both the TS tests and the Go verifier (Task 8) check |
| `TaskSigner.sign(task)` | Base64 Ed25519 over `canonicalJson(task without signature)`; `TASK_SIGNING_KEY` must be Ed25519 |
| `TasksService.create(ctx, agentId, input)` | Defaults: TTL 600 s, max runtime 60 s, max response 64 KiB; refuses revoked agents (409); wakes pollers through Redis `agent-tasks:<agentId>` |
| `GET /agent/v1/tasks?wait=0..25` | Marks past-due queued tasks `expired`, claims queued unexpired ones with a conditional update (no double delivery), else waits for a notification |
| `POST /agent/v1/tasks/:id/result` | Only the owning agent and only for `delivered` tasks (else 404); over `maxResponseBytes` → 413; stores result, sets `succeeded`/`failed` |
| `POST /agent/v1/streams/:sessionId/chunks` | Schema-checked chunk for an open, unexpired session of this agent (else 404); published to Redis `stream:<sessionId>` (browser relay lands in M10) |
| `POST /api/v1/agents/:id/diagnostics` (`agent.enroll`), `GET /api/v1/agents/:id/tasks` (`agent.view`) | Queue an `inspect` task `{ target: 'agent_info' }`; list the latest 20 tasks with results |
| `TaskNotifier` | One Redis pattern subscriber per API process plus in-process waiters |
